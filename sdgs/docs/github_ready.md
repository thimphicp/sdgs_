# GitHub Ready Checklist

## 이 폴더는 바로 올려도 되는가

네. `sdgs/` 폴더는 공개 저장소 업로드용으로 정리되어 있습니다.

## 공개 저장소에 포함되는 것

- API 서버 코드
- 웹 백엔드 코드
- 문서
- 환경변수 예제
- `.gitignore`

## 공개 저장소에 포함되면 안 되는 것

- 실제 모델 파일
- `.env`
- 개인 비밀키
- 분류기 레포 내부의 대용량 가중치
- 터널 주소가 들어간 실사용 설정 파일

## 업로드 전 확인

1. `.env` 파일이 없는지 확인
2. `*.pt`, `*.safetensors`, `*.bin` 파일이 없는지 확인
3. `CLASSIFIER_COMMAND`에 개인 경로를 하드코딩하지 않았는지 확인
4. `LOCAL_LLM_API_KEY`가 코드에 직접 들어가 있지 않은지 확인
